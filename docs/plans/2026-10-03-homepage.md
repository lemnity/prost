## Context

Сайт-каталог сувенирной компании Prostyle (Тюмень, B2B). Сейчас делаем **только главную страницу**.
Позже появятся: каталог из API сторонних складов (Oasis и др.), админка, личный кабинет пользователя, корзина.
Поэтому данные главной идут через тонкий слой `src/lib/catalog` (сейчас — статические данные, позже — провайдеры складов),
а контент страницы лежит в `src/content/*` (позже — CMS/админка).

## Global Constraints

- **Макет 1:1 с референсом** (`docs/design/reference-home.png`): порядок секций, сетки, пропорции, цвета, радиусы, иконки, тексты-лейблы. Если сомневаешься — открой нужный кроп из `docs/design/sections/` и сравни.
- **Логотип — оригинальный файл без изменений**: `public/images/brand/logo.svg` (зелёно-серый «PRO STYLE / BUSINESS GIFTS»). Не перерисовывать, не перекрашивать, не заменять красным знаком из макета.
- **Стек**: Next.js 16 (App Router, TypeScript, `src/` dir), Tailwind CSS v4, `next/font/google` (Inter, subsets `latin` + `cyrillic`), `lucide-react` для иконок. Других зависимостей не добавлять. Менеджер пакетов — `npm`.
- **Скорость** (жёсткое требование заказчика):
  - `/` рендерится статически (в выводе `next build` маршрут `/` помечен `○ Static`).
  - Все компоненты — серверные. `"use client"` запрещён на главной, кроме случаев, явно разрешённых в задаче. Интерактив без JS там, где возможно (`<details>`, CSS `:hover`/`:focus-within`, якоря).
  - Все картинки через `next/image` с корректным `sizes`; только hero — `priority`. Остальные — lazy (по умолчанию).
  - Никаких внешних запросов в рантайме (шрифты — через next/font, картинки — локальные из `public/`).
- **Цвета (токены в `@theme` в `src/app/globals.css`)**:
  - `--color-brand: #D02E31` (кнопки, акценты, ссылки «Смотреть все…»), `--color-brand-hover: #B5252A`
  - `--color-ink: #1A1A1A` (заголовки и основной текст), `--color-muted: #6F7170` (вторичный текст), `--color-faint: #A9AAAB` (номера шагов, плейсхолдеры)
  - `--color-surface: #F5F5F4` (плитки категорий, карточки шагов/нанесения/отзывов, поле поиска), `--color-topbar: #F5F3F3`, `--color-line: #ECECEC` (рамки карточек товаров, разделители)
  - `--color-case: #1F6FA8` (названия клиентов в «Наших работах»), бейдж «Новинка»: фон `#DDF3E9`, текст `#2F8A64`
- **Типографика**: Inter. H1 hero 44px/1.12 bold (`tracking-tight`); заголовки секций 26px bold; заголовки карточек 14–15px semibold; основной текст 14–15px; мелкий 12–13px. На мобиле H1 30px, H2 22px.
- **Сетка**: контейнер `max-w-[1280px] mx-auto px-4 md:px-8` (контент 1216px на десктопе). Вертикальный ритм секций: `py-6 md:py-8` у секции, заголовок→контент 20–24px. Радиус карточек/плиток 10px (`rounded-[10px]`), кнопок 8px.
- **Ссылки «Смотреть все …»** в шапке секций: справа, красные, 13px, с иконкой `ArrowRight` 14px.
- **Адаптив**: десктоп 1280+ как в макете; ≤1024 и ≤640 — сетки сжимаются (указано в задачах), горизонтальные ленты со `snap-x` и скрытым скроллбаром допустимы. Нет горизонтального скролла у `body` ни на одной ширине от 360px.
- **Доступность**: видимый `focus-visible` (outline 2px brand), `alt` у содержательных картинок, `aria-label` у иконочных кнопок, семантика `header/nav/main/section/footer`, у каждой секции `aria-labelledby` на её `h2`. `prefers-reduced-motion` — без анимаций.
- **Язык**: `<html lang="ru">`. Metadata: title «Корпоративные подарки и сувениры с логотипом в Тюмени — ProStyle», description «Онлайн-заказ подарков, бизнес-сувениров с нанесением и без.»
- **Данные**: тексты, контакты, категории, новинки, отзывы, виды нанесения — из файлов, указанных в задачах (взяты с prostyle.gifts). Не выдумывать новых фактов.
- Внутренние ссылки на ещё не существующие страницы допустимы (каталог/кабинет появятся позже). Ссылки с `href` пустым/`#` запрещены — если URL нет, рендерить не-ссылку.
- Проверка каждой задачи: `npm run lint` и `npm run build` проходят без ошибок и предупреждений TypeScript.
